## Private pilot coverage

The private file contains 29 records, all with exact locally extracted source text and both PDF/print page locators. Categories: one species, class, subclass, background, fighting style, weapon, armor, mastery and equipment package; two feats and resources; nine class features; seven proficiencies.

Review distribution: 17 `engine-verified`, 12 `mechanics-reviewed`, zero merely `extracted` or `text-reviewed`. The lower status is deliberate where the current effect vocabulary cannot yet express the mechanic without losing meaning.

The production path validated schema, duplicate IDs, all required links, one unavailable optional dependency warning, atomic import, repeated pack-version conflict and repeated entry-revision conflict. Synthetic tests cover required-dependency failure, cross-pack references, deterministic conflicts, stale previews, cancellation and rollback after a later pack write fails.

## Remaining risks

1. Dice-valued and roll-replacement effects are not expressive enough for Savage Attacker, Tactical Mind and all Remarkable Athlete behavior.
2. Equipment packages need first-class contents, alternative currency, quantities and replacement choices rather than an aggregate item.
3. Multiclass prerequisites and progression merging are not modeled deeply enough for full class coverage.
4. Spell scaling covers level-linked effects but needs pilots for every unusual target, area, duration and upcast idiom.
5. Monster actions, recharge, legendary reactions and summon overrides need richer discriminated structures.
6. Errata/reprint conflict policy needs a real two-edition pilot, not only synthetic collision tests.
7. Structural validation exists for all effects, but the rules engine does not execute every structurally valid variant yet.
8. The manually assembled Brammel mechanics require an independent rules review before character-builder calculations can rely on them.

## Gate

- Schema v2 / Brammel pilot: **GO** for continued controlled pilots.
- Full PHB conversion: **NO-GO**.
- Reconsider the full-conversion gate after effect-vocabulary expansion, equipment-bundle modeling, independent mechanics review, and a second pilot containing spells plus multiclass or replacement edges.
