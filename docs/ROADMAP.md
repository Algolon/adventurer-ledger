# Roadmap

## M0 — Foundation (complete)

Strict Next.js shell, initial domain model, Dexie database, Zod content-pack boundary, declarative rules engine, PWA support, and smoke tests.

## M1 — Private Content Pipeline (complete)

One local-first vertical slice for source/pack/entry CRUD, a pack editor, safe import preview and transactional confirmation, record versioning, restricted-export consent, sanitized validation, compendium discovery, and unit/integration/Playwright coverage.

## M1.1 — PWA/offline foundation (complete)

Static Next.js export, installable manifest and maskable icons, build-derived app-shell precaching, controlled service-worker updates, offline navigation fallback, cache cleanup, local storage/quota monitoring, persistent-storage requests, offline user journeys, and a generated 25,000-entry benchmark.

## M1.2 — GitHub Pages deployment readiness (complete)

Portable root/project base paths, scoped manifest and worker assets, cache-consistent controlled updates, truthful offline status, root and Pages browser matrices, two-build update regression, generated-artifact verification, and a branch-only temporary Pages workflow.

## M1.3 / M1.4 — Private library schema and rules-engine coverage (complete)

Private-library schema v2, typed progressions and relations, dependency-set imports, exhaustive effect-runtime dispositions, typed action-economy grants, choice and equipment resolution, and derived character state.

## M2.1 — Brammel character vertical slice (implemented; not yet certified)

Character drafts, committed characters, immutable versions, restore snapshots, runtime state, a session action log and typed overrides on Dexie v5; the seven M2.1 application services with their transaction matrix; the application-layer derived resolver; the original synthetic level 1–2 content; and the mobile-first library, nine-step builder, play sheet, level-up and file-transfer surfaces.

Bounded to levels 1 and 2 of one synthetic class. Level 3–20 progression, subclasses, multiclassing, spells, QR transfer and random dice results stay deferred.

M2.1 is not marked complete. Its verification ladder is recorded in
[`CURRENT.md`](CURRENT.md): implemented, verified locally, verified by GitHub CI,
verified in a browser, and still requiring physical Android validation. The next
milestone stays unset until a physical-device acceptance run has happened and the
draft PR has been reviewed.

## M2.2 — Progression breadth (candidate next, not started)

Levels 3–20 for the synthetic path, subclass selection and subclass-feature progression, and the broader content the same contracts already accommodate. It must not start before M2.1 is certified.

## Public M1.5 — shared rules-engine correction (separate track)

The five reproduced pilot gaps G-1 to G-5 remain open against the shared M1.4 engine. M2.1 avoids them through authoring patterns and repairs none of them; see [`M2.1_ENGINE_INTERACTION.md`](M2.1_ENGINE_INTERACTION.md).

## Later

- M3: print output, richer history browsing and safe character export modes;
- M4: encrypted vault backups, recovery workflows, accessibility and deeper large-pack profiling;
- M5: optional desktop packaging and explicitly opt-in encrypted sync.

Scope remains local-first. Cloud accounts, server persistence, broad rules coverage, and copied non-SRD content are not prerequisites for M1 or M2.
